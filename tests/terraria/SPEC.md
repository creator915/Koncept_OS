# 简化版单机《泰拉瑞亚》需求文档

> 版本：v2.0
> 范围：单机模式，前硬模式（最终 Boss 为血肉墙），单一邪恶生物群落（腐化）

---

## 1. 项目概述

### 1.1 项目目的

复刻《泰拉瑞亚》最核心的体验循环：**砍树 → 建房 → 制作 → 探险 → 打 Boss → 升级装备**。游戏从角色创建开始，玩家在 2D 横版世界中探索、采集、建造、战斗，最终击败血肉墙完成主线。

### 1.2 项目范围

本文档定义的全部功能即为需要实现的全部功能：

- 单人模式，单一难度（软核：死亡掉部分铜钱）
- 1 种世界尺寸：4200 × 1200 物块
- 9 种生物群落：森林、沙漠、雪原、丛林、海洋、腐化、地牢、地狱、太空
- 4 个主线 Boss：克苏鲁之眼、世界吞噬者、骷髅王、血肉墙；1 个可选 Boss：史莱姆王
- 7 名可入住 NPC 与 1 名特殊 NPC（老人）
- 60 种物块、35 种敌怪、约 90 条配方
- 击败血肉墙后进入"通关"状态，世界继续可玩，但不再有新内容

### 1.3 术语表

| 术语 | 含义 |
|---|---|
| 物块 / Tile | 世界由网格物块构成，每格 16×16 像素 |
| 前景层 | 决定碰撞的实心物块层 |
| 背景墙 | 不阻挡通行的装饰层，房屋判定必需 |
| 工作站 | 制作物品时玩家必须靠近的物块 |
| 进度阶段 | 玩家依次解锁的内容门槛，由击败的 Boss 数决定 |
| AI 编号 | 敌怪行为模板的索引，详见 §13.2 |

## 2. 系统架构

### 2.1 模块划分

```
core         主循环、计时、输入、资源、配置
render       渲染、相机、光照、粒子
world        世界数据、世界生成、Tile、生物群落
physics      碰撞、重力、流体
entity       Entity 基类、玩家、敌怪、NPC、抛射物、掉落物
item         物品定义、背包、堆叠、装备
craft        配方、合成判定
combat       伤害、Buff/Debuff、武器逻辑
boss         Boss 状态机
ui           HUD、菜单、面板
save         存档序列化
audio        BGM、音效
data         物块/物品/敌怪/配方等静态表（直接内嵌于代码常量中）
```

### 2.2 帧循环

游戏运行在固定逻辑帧率 60 FPS：

1. **输入采样**：键盘、鼠标
2. **逻辑更新**（按以下顺序）：
   1. 玩家输入响应、移动、动作
   2. 物理与碰撞
   3. 敌怪 AI、NPC、抛射物、掉落物
   4. 世界更新（液体流动、植物生长、事件触发）
   5. UI 更新
3. **渲染**：背景 → 远景墙 → 物块层 → 实体层 → 抛射物 → 粒子 → 玩家 → 前景效果 → UI
4. **音效播放**

如帧时不足，最多跳过 5 帧逻辑以追赶。

## 3. 核心数据结构

### 3.1 世界（World）

```
World {
  width = 4200, height = 1200
  tiles[width][height]      // 前景物块
  walls[width][height]      // 背景墙
  liquid[width][height]     // 液体（水/熔岩）
  spawnX, spawnY            // 出生点
  time                      // 0..86400，对应 24 小时游戏时间
  day                       // 第几天
  isBloodMoon               // 是否血月
  defeatedBosses            // 已击败 Boss 的集合
  meteorFallen              // 是否已坠落陨石
  shadowOrbsBroken          // 已破碎的暗影珠数量
  npcsAlive                 // 已入住 NPC 列表
  seed                      // 世界种子
}
```

### 3.2 Tile（前景物块）

```
Tile {
  type                      // 物块类型，见 §6.1
  hp                        // 当前剩余血量（破坏进度）
  variant                   // 纹理变体编号
  liquid                    // 0..255，液体高度
  isActive                  // 是否存在物块
}
```

### 3.3 玩家（Player）

```
Player {
  x, y, vx, vy
  width = 20, height = 42
  facing                    // -1 或 1
  hp, hpMax                 // 初始 100，最大 400
  mp, mpMax                 // 初始 20，最大 200
  defense                   // 当前总防御
  inventory[50]             // 含 10 格快捷栏 + 40 格主背包
  hotbar[10]                // 与 inventory[0..9] 同一份数据
  armorSlots[3]             // 头/胸/腿
  accessorySlots[5]
  trashSlot
  mouseSlot
  ammoSlots[4]
  buffs                     // 当前激活的 Buff/Debuff 列表
  attackCooldown
  spawnPoint                // 床绑定的复活点
}
```

### 3.4 实体通用基类（Entity）

```
Entity {
  id, x, y, vx, vy
  width, height
  hp, hpMax
  isOnGround
  immunityTimer             // 受击无敌帧
  ai                        // AI 状态数据
  type
}
```

派生：`PlayerEntity`、`Enemy`、`NPC`、`Projectile`、`ItemDrop`。

### 3.5 物品（ItemStack）

```
ItemStack {
  itemId
  count                     // 1..maxStack
  prefix                    // 武器前缀，0..7
}
```

### 3.6 配方（Recipe）

```
Recipe {
  result                    // { itemId, count }
  ingredients               // [{ itemId, count }, ...]
  requiredStations          // [TileType, ...]
}
```

## 4. 引擎核心

### 4.1 主循环

- 固定 60 Hz 逻辑帧；可变渲染帧率（vsync 开启）。
- 状态栈：`MainMenu` → `WorldSelect` → `CharSelect` → `InGame` → `Pause` → `GameOver/Victory`。
- 暂停与保存退出时立即触发自动存档。

### 4.2 输入与按键映射

| 操作 | 默认键 |
|---|---|
| 左/右移动 | A / D |
| 跳跃 | 空格 |
| 使用物品 / 攻击 | 鼠标左键 |
| 右键交互（NPC 对话、开门、使用饰品） | 鼠标右键 |
| 打开背包 / 关闭菜单 | ESC |
| 大地图 | M |
| 切换快捷栏 | 1–0 / 鼠标滚轮 |
| 智能光标 | Ctrl |
| 快速归位 | Shift + 左键 |
| 钩爪 | E |
| 丢弃物品 | Q |

支持自定义按键绑定，写入配置文件。

### 4.3 资源管理

启动时一次性加载所有图像与音效到内存。提供 `getSprite(id)`、`getSound(id)` 接口，命中即返回。所有同类型纹理打包成纹理图集以减少绘制调用。

### 4.4 时间系统

- 游戏一天 = 现实 24 分钟。
  - 白天：07:30 – 19:30，共 15 分钟现实时间
  - 夜晚：19:30 – 07:30，共 9 分钟现实时间
- 系统对外暴露：当前是白天/夜晚、是否日出/日落瞬间、是否血月、是否新的一天开始。

## 5. 渲染系统

### 5.1 相机

- 平滑跟随玩家（带阻尼）。打开大地图时切换为自由相机。
- 边界限制：不超出世界边缘。

### 5.2 物块渲染

1. 仅渲染相机视野内的物块，外加 2 格边界。
2. 同种物块批量绘制（顶点合并 + 纹理图集）。
3. 物块自动边缘适配：根据 8 邻接关系选择正确的纹理变体（共 47 种连通形态）。
4. 草、藤蔓、家具等"覆盖型"物块单独渲染。
5. 背景墙先于前景物块渲染，颜色压暗 50%。

### 5.3 光照

每个物块有一个 `light` 值（0..1）。

- 光源：阳光（顶部空气块直射 = 1.0）、火把（0.9）、熔岩（0.7）、玩家持有的发光物（0.6）。
- 每帧从光源做衰减扩散：`light(neighbor) = max(light(neighbor), light(self) - decay)`
  - decay：空气 0.04，物块 0.16，水 0.08
- 限制扩散迭代为 3 次以保性能。
- 整体作为屏幕乘法层叠加渲染。

### 5.4 粒子系统

- 粒子池上限 1024 个活跃粒子。
- 类型：方块碎片、血液、星光、火星、灰尘、攻击命中、死亡爆裂。
- 粒子带速度、重力、生命周期、可选的颜色渐变与缩放。

### 6.2 物块属性

每种物块声明：

- **hardness**：决定挖掘耗时（=hp 上限）
- **pickaxePower**：所需鎬等级
- **placement**：放置规则（自由放置 / 需要支撑物块 / 需要背景墙）
- **drops**：掉落物品 ID 与数量
- **physics**：是否阻挡通行、是否半透明、是否单向通过
- **gravity**：是否受重力（沙、雪受重力下落）
- **growable**：是否可生长（草扩散、藤蔓向下）

### 6.3 液体

仅支持水与熔岩两种。

- 网格液体模型：每个 Tile 有 0..255 的液体量
- 每帧按高度差向相邻空格扩散：高位向低位流动，每帧最多移动 32 单位
- 水 + 熔岩接触 → 黑曜石生成，双方各消耗 1 格
- 玩家进入水：减速 50%、可游泳；进入熔岩：每帧扣血并施加"着火！"Debuff
- 流速控制：每个 Tile 每帧最多更新一次，避免连锁更新爆炸

## 7. 世界生成

### 7.1 世界尺寸

宽 4200 × 高 1200 物块。地表线约位于 y = 280。

### 7.2 层级划分

| 层 | y 范围 | 主要内容 |
|---|---|---|
| 太空 | 0 – 80 | 漂浮岛 |
| 地表 | 80 – 280 | 各表层生物群落 |
| 地下 | 280 – 500 | 各群落的地下版本 |
| 洞穴 | 500 – 1100 | 石头主体、矿洞、生命水晶 |
| 地狱 | 1100 – 1200 | 灰烬、熔岩湖、恶魔石屋 |

### 7.3 生成步骤

按顺序执行：

1. **基础地形**：用 4 层叠加柏林噪声生成地表起伏，幅度 ±20 格。
2. **群落水平布置**：按 §7.6 世界地图布局执行。简述：中央 800 格为森林（出生区），向左依次为沙漠（200）、西森林（520）、雪原（600）、海洋（380）；向右依次为沙漠（400）、丛林（600）、远东森林（520）、海洋（380）。腐化 1 块（宽 300 格，远离出生点 ≥ 600 格，随机左或右且与丛林异侧）。30% 概率丛林与雪原对调位置。详细 x 区间见 §7.6.1。
3. **填充层级**：地表填泥土+草，地下填石头，地狱填灰烬。
4. **洞穴**：用元胞自动机迭代 6 次生成不规则洞穴，密度系数 0.45。
5. **矿石分布**：每种矿石按以下密度分布：
   - 铜矿：密度 0.012，所有层
   - 铁矿：密度 0.010，y > 350
   - 银矿：密度 0.008，y > 450
   - 金矿：密度 0.006，y > 600
   - 地狱石：密度 0.020，仅地狱层
6. **特殊地形**：
   - 漂浮岛：2–4 个，y < 80，含云块平台与天蓝箱
   - 金字塔：沙漠下方 10% 概率生成，含金箱
   - 地牢：在世界靠左或靠右一端（与腐化对侧），蓝/绿/粉地牢砖蜿蜒向下至 y = 800
   - 地狱恶魔石小屋：地狱中分布 6–10 座，含暗影箱
7. **腐化深井**：3 条垂直深井从地表通向地下 y = 600，井壁用紫石。
8. **暗影珠**：每条深井底部生成 1 个暗影珠，共 3 个。
9. **恶魔祭坛**：每条腐化深井底部生成 1 个，共 3 个。
10. **生命水晶**：洞穴层随机散布 20 个。
11. **宝箱**：表层木箱 15 个、地下金箱 25 个、地牢金箱 30 个、地狱暗影箱 10 个。
12. **植被**：
    - 草地放置橡子并立即生长成树（约每 20 格 1 棵）
    - 雪原生成针叶树
    - 丛林生成红木与丛林草、藤蔓
    - 沙漠表面生成仙人掌
13. **平滑**：剔除孤立物块、修补单格悬空。

| 天蓝箱（漂浮岛） | 闪耀红气球 / 露水之星 / 阳光斩剑 / 闪电靴 / 风暴枪 | 金币 1–5、星粉 |
| 地牢金箱 | 鬼火法杖 / 魔法飞弹 / 巫师帽 / 鬼斧 / 蓝月（弓） / 蛇怪法杖 | 金币 5–10、地牢钥匙 1 |

### 7.5 随机性

全程使用 `seed` 控制的伪随机数生成器，保证同种子生成同世界。玩家可输入种子，留空则使用当前时间戳。

### 7.6 世界地图布局（横向边界）

世界总宽 4200 物块，玩家出生点固定在世界中心 `x = 2100`（位于森林群落正中），高度为地表草地最高点上方 3 格。坐标以**距离出生点的水平距离 |Δx|** 为准，单位 = 物块；负值表示左侧，正值表示右侧。

#### 7.6.1 主轴群落带（地表 y ∈ [80, 280]）

群落沿 X 轴线性铺开，左右大体对称（腐化随机偏向一侧打破对称）。下表给出**每个群落区段的 x 物块范围**及离出生点的距离：

| # | 群落 | x 区间（物块） | 距离出生点 \|Δx\| | 宽度 | 备注 |
|---|---|---|---|---|---|
| 1 | 海洋（左端） | 0 – 380 | 1720 – 2100 | 380 | 世界最左 380 格，水深 30；尽头是世界边界（不可逾越） |
| 2 | 雪原 | 380 – 980 | 1120 – 1720 | 600 | 表面积雪、针叶树；地下含冰穴 |
| 3 | 沙漠（左） | 980 – 1180 | 920 – 1120 | 200 | 一对沙漠中较小的一块；含金字塔候选点 |
| 4 | 森林 - 西段 | 1180 – 1700 | 400 – 920 | 520 | 与中央森林同质，过渡用 |
| 5 | 丛林 | 1700 – 2300 ⊕ | 距出生点 ≤ 400（仅当随机选中"丛林贴近中心"分支时） | 600 | **见 7.6.3 随机分支**；否则丛林位于右侧 2700–3300 |

#### 7.6.2 腐化带（异常群落，不参与对称）

腐化是一块宽 300 的垂直带，**远离出生点 ≥ 600**，随机出现在以下两个区段之一：

- 左侧候选：`x ∈ [600, 1500]` 中随机起点（保证不切到海洋）
- 右侧候选：`x ∈ [2700, 3600]` 中随机起点

腐化带从地表向下贯穿 3 条紫石深井至 `y = 600`，井底放置暗影珠 + 恶魔祭坛（见 7.3 步骤 7–9）。腐化带覆盖范围内的群落判定优先级高于本来的群落（参见 16.1 的优先级表）。

#### 7.6.3 群落随机分支

世界生成时一次性掷骰：

- **70% 概率**：丛林位于右侧 2700–3300（默认布局）
- **30% 概率**：丛林与雪原对调（丛林移至左侧 380–980，雪原移至右侧 2700–3300）

腐化与丛林必定位于**不同侧**——若两者随机结果在同侧，腐化重新掷骰直到落入对侧候选区间。

#### 7.6.4 纵向分层与"走多远遇到什么"

玩家从出生点（中心森林）出发：

| 行为 | 触发距离/深度 | 进入的层/群落 |
|---|---|---|
| 横向移动 0 – 400 格 | 任一方向 | 中央森林（安全区，必为森林） |
| 横向移动 400 – 1000 格 | 左 | 进入沙漠（左）/ 西森林 |
| 横向移动 400 – 1000 格 | 右 | 进入沙漠（右）/ 东森林 / 丛林（默认分支） |
| 横向移动 600 – 1200 格 | 触发腐化方向 | 进入腐化带（紫石/紫沙地表 + 紫色 BGM） |
| 横向移动 1000 – 1700 格 | 左 | 进入雪原（默认分支）或丛林（30% 分支） |
| 横向移动 1720 格 | 任一方向 | 进入海洋（开始有水，可游泳；触发海洋 BGM） |
| 横向移动 ≥ 2100 格 | 任一方向 | 撞到世界边界（不可移动，玩家被弹回） |
| 向下挖 0 – 200 格 | y < 280 | 仍在地表层 |
| 向下挖 200 – 220 格 | y ≈ 280 – 500 | 进入地下层（同群落地下变种） |
| 向下挖 220 – 820 格 | y ≈ 500 – 1100 | 进入洞穴层（生命水晶、矿石密度上升） |
| 向下挖 ≥ 820 格 | y ≥ 1100 | 进入地狱（强制高温伤害，无 ObsidianSkull 时 -2HP/2s） |
| 向上跳/钩 至 y < 80 | 高度 ≥ 200 格以上 | 进入太空（重力 50%，可达漂浮岛） |

#### 7.6.5 出生点保护半径

以出生点 `(2100, 280)` 为中心、半径 `r = 400` 的圆形区域内：

- 强制群落 = 森林，不允许腐化、沙漠、雪原、丛林任一物块在生成阶段写入
- 不生成任何 Boss 召唤所需的"邪恶"地形（暗影珠 / 祭坛 / 地狱井）
- 该区域作为玩家初始建造与 NPC 入住的"安全屋"备选地

#### 7.6.6 边界处理

- X = 0 与 X = 4199 列填充为不可挖掘的"世界边界石"（新增隐式物块类型，AI 与玩家都无法穿越）
- Y = 0 行为天空上限（玩家可达但实体不能再向上）
- Y = 1199 行为地狱底，下方为不可逾越的"基岩"

## 8. 物理与碰撞

### 8.1 玩家与实体物理

- 重力 `g = 0.4 像素/帧²`，最大下落速度 16/帧
- 跳跃初速 -10/帧，"长按跳跃"延长 7 帧上升
- 移动加速 0.5/帧，最大水平速度 5/帧（地面）/ 4（空中）
- AABB 碰撞：每帧先按 vx 移动并解算 X 轴碰撞，再按 vy 移动并解算 Y 轴
- 平台：仅自上而下落到时阻挡；按 S + 跳跃可下落穿过
- "踏台阶"：水平移动时若前方是 1 格高物块，自动抬升

### 8.2 抛射物

抛射物结构：

```
Projectile {
  x, y, vx, vy
  width, height
  damage
  knockback
  owner                     // 玩家 / 敌怪
  lifetime                  // 剩余帧数
  affectedByGravity
  penetration               // 可穿透次数
  onHitBehavior             // 消失 / 反弹 / 爆炸
  type
}
```

### 8.3 击退

任何带"击退"属性的攻击命中后，向命中方向施加水平速度 + 垂直速度。Boss 与重型敌怪可有击退抗性（0–1 比例，0 = 完全免疫）。

## 9. 玩家系统

### 9.1 角色创建

- 难度：仅软核（死亡掉部分铜币，无其他惩罚）
- 外观：发型（10 种）、发色、瞳色、肤色、衣服颜色（4 部位 × HSL）
- 名字：1–20 字符
- 初始装备：铜短剑 1、铜镐 1、铜斧 1（位于背包前 3 格）

### 9.2 属性

| 属性 | 初始 | 上限 | 提升方式 |
|---|---|---|---|
| 生命值 | 100 | 400 | 使用生命水晶 +20，使用 15 颗到 400 |
| 魔力值 | 20 | 200 | 使用魔力水晶 +20，使用 9 颗到 200 |
| 防御 | 0 | — | 装备护甲 |
| 攻击 | 武器决定 | — | — |
| 移速 | 5 | — | 鞋类饰品（如赫尔墨斯靴 +20%） |

### 9.3 状态与动作

状态：站立、行走、跳跃、下落、游泳、使用物品、受伤、死亡。

- 使用物品时根据武器类型播放挥砍/瞄准动画
- 受伤进入 30 帧无敌时间，期间闪烁
- 玩家始终面向最近一次输入方向或鼠标方向

### 9.4 死亡与复活

- 死亡时掉落约 50% 的钱币作为可拾回的硬币堆

- 死亡处生成一块墓碑

### 9.5 Hp/Mp 自然恢复

- HP 自然再生：每秒恢复 `hpMax / 600`，受伤后 5 秒内不再生
- MP 自然再生：每秒恢复 `mpMax / 7`，使用魔法 0.5 秒内不再生
- 站立不动时再生速率提升 50%

### 15.2 NPC 战斗

每个入住 NPC：

- HP：250
- 防御：15
- 出现敌怪在房屋附近时主动用武器攻击
- 不会主动追出过远（限于屏幕内）
- 死亡后 24 游戏小时后，若房屋仍可用且条件满足，重新入住

### 15.3 房屋判定

房屋有效需同时满足：

1. 房屋为封闭矩形（洪水填充测试不漏到外部）
2. 内部空间至少 60 格，尺寸至少 6×10（含墙体）
3. 至少 1 扇门或 1 个平台（NPC 出入口）
4. 内部完整背景墙（每个内部空格都有 wall）
5. 内部含：椅子（或同效家具）、桌子（或同效家具）、光源（火把/蜡烛/篝火）
6. 房屋不在腐化、地狱、海洋区域

实现：

- 玩家放置/破坏物块时触发"房屋脏标记"
- 每 1 秒一次扫描所有"门或平台"附近的潜在房屋
- 通过的房屋加入"可用房屋"列表
- 空闲 NPC 自动入住空房屋；玩家可在 NPC 设置面板手动指定

### 15.4 对话与商店

- 玩家右键 NPC：打开对话框
- 对话框选项：交谈、购买（仅商店 NPC）、帮助（仅向导）、治疗（仅护士）、重铸（仅哥布林工匠）、家
- 交谈：随机话语，每 NPC 准备 8 句
- 购买：左为出售栏（NPC 物品），右为玩家背包；左键购买 1 件，Shift + 左键一次买 1 组堆叠
- "家"：将该 NPC 移动到玩家当前指定的房屋

### 15.5 货币与价格

- 每件商品基础售价 = `ItemDef.value × 2`
- 玩家可将物品卖给商人：售出价 = `ItemDef.value`
- 货币换算：1 白金 = 100 金 = 10000 银 = 1000000 铜

## 17. 事件系统

### 17.1 日夜循环

- 日落（19:30）：BGM 切换为夜晚版本，开始生成夜晚怪
- 日出（07:30）：销毁仍在屏幕外的所有夜晚怪；如有 Boss 战进行中，Boss 不消失（骷髅王特例：天亮直接传送至玩家上方秒杀）

### 17.2 血月

触发：进入夜晚瞬间，1/9 概率（要求世界已有至少 1 名 NPC 入住）。

- 怪物上限 +5
- 僵尸可破门（连续撞击 5 秒后木门被破坏）
- 兔子变为腐化兔子（攻击玩家）
- 增加专属怪物：血腥僵尸、滴水兽
- 屏幕周围有红色光晕，月亮变血色

结束：日出。

### 17.3 陨石坠落

触发：击败 EOW 后，每天夜晚 1/3 概率，且世界尚未有陨石。

效果：

- 在地表随机点（远离玩家出生点 ≥ 500 格）生成约 30×20 格的陨石坑
- 陨石坑由陨石矿与少量黑曜石构成
- 玩家进入陨石区附近会被陨石头怪追击

## 19. 存档系统

### 19.1 存档目录结构

```
saves/
  chars/
    Alice.char
    Bob.char
  worlds/
    Forest.wld
    Forest.wld.bak
```

### 19.2 角色文件 .char

二进制格式，包含：

- 文件头：Magic（4 字节 "TCHR"）、版本号（u32）
- 名字（UTF-8 字符串，长度前缀）
- 外观：发型、发色、瞳色、肤色、衣服色（共 6 个 RGBA 字段）
- HP 上限、MP 上限、当前 HP / MP
- 完整背包（含装备）：每槽 ItemId(u32) + count(u32) + prefix(u8)
- 已击败 Boss 列表（位字段）
- 游玩时长（秒，u64）
- 文件尾：CRC32 校验

### 19.3 世界文件 .wld

二进制格式，包含：

- 文件头：Magic（4 字节 "TWLD"）、版本号（u32）
- 世界元数据：名字、种子、宽、高、出生点、创建时间、游玩时长
- Tiles：用 RLE 压缩存储（同种连续物块合并成一段）
- Walls：同上
- Liquids：稀疏存储 (x, y, type, amount) 列表
- Entities：所有 NPC、宝箱内容、特殊结构标记
- WorldFlags：是否击败各 Boss、是否陨石已坠落、暗影珠破碎数等
- 文件尾：CRC32 校验

### 19.4 自动存档与崩溃恢复

- 触发时机：暂停、保存退出、每 5 分钟、每次击败 Boss 时
- 写入流程：先写入 `.tmp`，写完后原子替换为正式文件；同时保留前一份为 `.bak`
- 启动加载：优先加载主文件；CRC 失败时弹窗提示并尝试 `.bak`
- 启动主菜单时显示存档列表，标记损坏的存档

## 21. 进度推进路径

### 21.1 第 0 天（出生）

1. 砍 ≥ 100 木材，制作工作台
2. 制作木剑、木弓、木箭
3. 用木材建简陋避难所（封闭、有门、火把、椅子、桌子）
4. 入夜抵御僵尸与恶魔之眼

### 21.2 第 1–3 天（铜铁阶段）

1. 收集铜矿/铁矿、岩石
2. 造熔炉 → 制铜锭 → 造铜镐 + 铜剑
3. 凑齐 50 银币 → 召唤商人
4. 收集生命水晶 → 提升 HP

### 21.3 第 4–7 天（银金 + 探索）

1. 银金套装、金弓
2. 制作床并设定复活点
3. 探索沙漠（金字塔）、雪原、漂浮岛（天蓝箱）
4. 制作炸弹（爆破工入住）

### 21.4 第 8–14 天（Boss 1：克苏鲁之眼）

1. 收集 6 个晶状体合成"魔眼"
2. 平整 50 格的战斗平台 + 火把
3. 击败 EOC，得暗影鳞 30+ → 暗影套装
4. 树妖入住

### 21.5 第 15–20 天（Boss 2：世界吞噬者）

1. 在腐化深井破碎 3 个暗影珠（连续破或合成蠕虫诱饵召唤）
2. 击败 EOW，得魔矿 + 暗影鳞
3. 升级到暗影套 + 魔矿镐 + 暗影武器

### 21.6 第 21–30 天（陨石与火力升级）

1. 等待陨石坠落，开采陨石矿
2. 制作陨石套 + 太空枪
3. 在洞穴击败若干普通骷髅，触发哥布林工匠救援，使其入住

### 21.7 第 31–40 天（Boss 3：骷髅王）

1. 找到老人（地牢入口处）
2. 夜晚召唤骷髅王
3. 击败后地牢解锁，深入获得地牢装备
4. 收集 LightsBane / WarAxe / FieryGreatsword + 地牢宝箱中的 Muramasa，在恶魔祭坛合成夜之刃

### 21.8 第 41–50 天（Boss 4：血肉墙，胜利！）

1. 准备地狱套（Molten Set）+ 地狱镐
2. 在地狱挖出至少 800 格平直跑道
3. 击杀巫毒恶魔获得 GuideVoodooDoll
4. 将 GuideVoodooDoll 扔入地狱熔岩 → 召唤血肉墙
5. 击败血肉墙 → 游戏胜利

胜利后游戏继续运行。屏幕显示"恭喜通关"。

## 22. 性能与质量目标
