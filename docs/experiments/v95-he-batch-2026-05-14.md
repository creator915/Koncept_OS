## 5. 单题明细

### HumanEval/0 — `has_close_elements`
- 算法：嵌套 `for i, for j>i` 严格 `< threshold` 早返回。
- 图结构：3 个外部属性（`float_list`, `threshold`, `close_result`）+ 2 个 object（`HasCloseElements` + `Caller` 作为外部边界 producer）。
- 验证：11 个 synthesized cases，含 SPEC 6 个示例 + 5 个边界（空列表、单元素、threshold 边界等），全部通过。

### HumanEval/14 — `all_prefixes`
- 算法：`for i in range(1, len(s)+1): out.append(s[:i])`。空字符串 → `[]`。
- 图结构：1 个 object，1 个外部输入属性 + 1 个 produces 属性。
- 验证：4 个 cases（空、单字符、多字符、含空格），全部通过。

### HumanEval/22 — `filter_integers`
- 算法：列表推导 `[v for v in values if isinstance(v, int) and type(v) is not bool]`。
- 关键边界：`True/False` 是 `int` 子类，SPEC 要求过滤掉 → `type() is not bool` 双重判定。
- 验证：5 个 chain cases + agent 主动补充的 9 个 pytest cross-check，全部通过。

### HumanEval/23 — `strlen`
- 算法：`n = 0; for _ in s: n += 1; return n`。
- storyPoints = 1 — 纯算术循环，是本批最简单的任务。
- 验证：7 个 cases（空 / 单字符 / 多字符 / 长字符串），全部通过。

### HumanEval/24 — `largest_divisor`
- 算法：从 `n-1` 向下扫，遇到第一个能整除的返回；`n=2` → `1`。
- storyPoints = 2 — 单循环 + 一次取模。
- 验证：6 个 cases，覆盖 SPEC 5 个示例 + 1 个额外。
